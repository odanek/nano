# @nano-ui/nano

A small, dependency-light UI library for the browser: functional components,
hooks, a typed JSX runtime, virtual DOM, and built-in CSS-in-JS.

```sh
npm install @nano-ui/nano
```

Enable the JSX runtime in `tsconfig.json`:

```json
{
  "compilerOptions": {
    "jsx": "react-jsx",
    "jsxImportSource": "@nano-ui/nano"
  }
}
```

See the [GitHub repository](https://github.com/odanek/nano#readme) for
documentation and examples.
